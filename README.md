# Chili's Restaurant Website

A inspired restaurant website built with **JavaScript**, **HTML**, and **CSS**, using **Webpack** for module bundling. This project simulates a simple single-page application (SPA) with multiple sections dynamically injected via JavaScript.

## ✨ Features

- ✅ Dynamic rendering using JavaScript modules
- ✅ Responsive layout with CSS Grid and Flexbox
- ✅ Organized file structure with Webpack
- ✅ Custom styling and layout without frameworks

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack (for bundling and module management)
